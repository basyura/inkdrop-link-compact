# テスト

Node.js 22 以降で `npm ci`、`npm test` を実行する。追加のテスト依存は不要。
`npm run test:coverage` で本体の `lib/` のカバレッジを確認できる。

## 検証範囲

| ファイル                | 対象                                                                                                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rendering.test.cjs`    | 通常・ノート・画像リンク、相対 URL、空・未完了の記法、入れ子、エスケープ、改行、日本語・絵文字、隣接リンク、装飾・移動用範囲、SVG、文字設定、元 URL と本文の保持 |
| `interactions.test.cjs` | 通常・Vim モードの選択補正、文書・行・リンクの境界、結合文字、複数カーソル、範囲選択、Enter、Backspace、Delete、編集中の展開と再短縮、変更位置の追従、文字入力   |

## テスト環境

- `helpers/harness.cjs` は Node.js の VM 内で本体のソースをそのまま読み込む。本体にテスト用の公開関数を追加せず、ソースの置換・コピーもしない。
- CodeMirror の `EditorState`、トランザクション、変更位置のマッピング、`ViewUpdate`、`ViewPlugin` の定義、キーマップ、装飾、`Compartment`、移動用範囲はインストール済みの実装を使用する。
- ヘッドレスのビューアダプターが、状態更新に合わせて本体プラグインの生成・更新・破棄を呼び出す。実際の `EditorView` は生成しない。
- Inkdrop の設定・ストア・コマンド・エディターロード通知・URI 起動、`event-kit` の購読管理、DOM 要素、`MutationObserver` はテスト用の代替実装を使う。
- テストごとに独立した VM と設定を作り、終了時に監視と購読を解除する。ノート本文・ユーザー設定・アプリにはアクセスしない。
- `--experimental-vm-modules` は本体の ES module と CommonJS が混在した形式を読み込むために使用する。Node.js の実験的機能に関する警告は想定内。
- 改行の CR / CRLF は CodeMirror が LF に正規化するため、本文保持はエディター状態の生成後と短縮後を比較する。

## 現在の解析仕様

リンク検出は Markdown の構文木ではなく文字列の走査による。コード内のリンク記法も短縮対象となり、タイトル付きリンクでは丸括弧内全体を URL として扱う。これらも現状の回帰テストに含めるが、CommonMark 準拠を保証するものではない。仕様を変更する場合は該当ケースも更新する。

## 別途必要な実機確認

自動テストの代替オブジェクトによる確認を実機確認として扱わない。次の項目は Inkdrop v6 で確認する。

- 実際の `EditorView` の描画、SVG の方向・サイズ・色・余白・行高、テーマとユーザー CSS の組み合わせ。
- OS のキー入力・マウス操作と CodeMirror のイベント配送、実際の Vim 拡張の `h` / `l`、矩形選択、カーソルの描画・再生成。
- IME の入力と変換。自動テストは `composing` フラグによる干渉防止のみ確認する。
- 起動・ノート切り替え時の実際の通知順序、通常リンクの外部起動、ノートリンクの画面遷移。
- 大量のリンク・カーソルを含む文書の描画性能と長時間利用時のメモリ。

テスト追加に伴う実機確認は未実施。本体ソースとスタイルの変更はない。
