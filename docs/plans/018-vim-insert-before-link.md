# Vim の挿入開始位置をリンクの前へ移す

## 目的

- 記号を非表示にした短縮リンクのラベル先頭で、Vim の通常モードから `i` で挿入モードへ入るとき、カーソルをリンク記法の開始位置へ移す。
- 行頭のリンクより前にも文字を入力できるようにする。

## 修正案

1. Vim のキー処理と選択補正の順序を確認し、通常モードの `i` とラベル先頭の空カーソルに対象を限定する。
2. 対象操作でカーソルを非表示の開始記法の前へ移し、既存の選択補正でラベル内へ戻らないようにする。通常・ノート・画像リンクの開始位置を確認する。
3. ラベル途中、挿入モード、範囲選択、短縮解除時などへの影響を回帰テストで確認する。
4. 現行仕様とテスト資料を更新する。

## 検証

- `npm test` で全テストを実行する。
- 編集した JavaScript ファイルを `node --check` で確認する。
- `npm pack --dry-run` と差分の確認を行う。
- 利用可能なら Inkdrop v6 と Vim の実機で、行頭のリンク前への入力と通常のラベル編集を確認する。検証による本文や設定の一時変更は復元し、未実施の確認は明記する。

## 実施結果

- Vim のキー処理へ `i` を渡す前に、短縮リンクのラベル先頭から記法開始位置へカーソルを移す処理を追加した。この位置への選択補正を一時的に抑え、次のキーまたは文書変更で解除する。
- 通常・ノート・画像リンク、前置文字、初期状態クラス未設定、他モード、選択、修飾キー、短縮解除、通常移動への復帰を回帰テストで確認した。
- `npm test` は全 179 件成功。編集した JavaScript の構文確認、`npm pack --dry-run`、`git diff --check` も成功した。
- Inkdrop のパッケージ参照先が本リポジトリであることを確認した。デバッグ接続は起動していなかった。画面操作ツールでアプリの表示は確認できたが、利用中のノートに対する操作と再起動は行っておらず、実際の Vim による挿入・ノート切り替えは未検証。本文や保存済み設定の変更は行っていない。
