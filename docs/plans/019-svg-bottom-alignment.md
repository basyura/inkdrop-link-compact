# SVG マークの下端揃え

## 目的

リンクタイトルと矢印マークの下端のずれを抑え、フォントサイズや種類に応じて位置が追従するようにする。

## 現状

- マークは本文の 90% の文字サイズで表示される。
- SVG は幅・高さが 1em で、`vertical-align: -0.125em` によってベースラインから位置を補正している。
- SVG の描画領域には下余白があり、要素の下端と矢印の下端は一致しない。

## 修正案

1. `styles/link-compact.css` の縦位置を `vertical-align: baseline` に変更し、SVG の下端を文字のベースラインに合わせる。
2. `lib/decorations.js` の SVG の描画領域を調整し、線幅と丸い線端を考慮して下余白を詰める。矢印の形状と方向は維持する。
3. サイズは em 単位のままとし、フォントごとの固定値やピクセル単位の位置補正を追加しない。
4. `docs/specs/link-detection-and-rendering.md` に確定した表示仕様を反映する。

英数字の通常の下端の基準となるベースラインへの追従を対象とする。g・p・y などの下降部や日本語の字形はベースラインからはみ出す場合があるため、すべての文字との可視下端の完全な一致は保証しない。

## 検証

- SVG の描画領域と線端が欠けないことを検証する回帰テストを追加する。
- `npm test` で全テストを実行する。
- 編集した JavaScript に `node --check` を実行する。
- `npm_config_cache=/tmp/link-compact-npm-cache npm pack --dry-run` で配布内容を確認する。
- Inkdrop の実画面で、日本語と英数字のタイトル、複数のフォント種類・サイズ、行高を確認する。設定や本文を一時変更する場合は元の状態を記録して復元する。
- 実画面確認で実施した項目と未実施の項目を区別して記録する。

## 進捗

- 実装開始の承認済み。
- SVG の下端は線端を含めて y=21 となるため、描画領域を `0 0 24 21` にする。縦横比による上下余白を避けるため、高さは幅の 21/24 倍とする。
- SVG の親はタイトルと同じ文字サイズを継承する。SVG の幅・高さ・左余白をそれぞれ `0.9em`・`0.7875em`・`0.135em` とし、従来の幅・描画スケール・余白を保つ。文字設定のマークは従来の 90% のままとする。
- 実装・仕様更新・回帰テスト追加済み。

- `npm test`: 全 185 件成功。
- `node --check lib/decorations.js`、`node --check test/rendering.test.cjs`: 成功。
- `npm_config_cache=/tmp/link-compact-npm-cache npm pack --dry-run`: 成功。
- `git diff --check`: 成功。
- Inkdrop のパッケージ参照先と読込済みソースが本リポジトリであることを確認した。
- 起動後の実エディターで、新しい描画領域、`text-bottom`、親からの文字サイズ継承を確認し、スクリーンショットで右上向きの矢印の表示を確認した。ユーザーの括弧を隠すスタイルが適用された状態で確認した。
- 複数フォントの確認には、Inkdrop のレンダラー内に一時的な表示領域を作成し、本体の装飾ビルダーから生成した実際の DOM を描画した。HackGen・Arial・serif、15px・24px、行高 1.4・2 の全 12 組合せで、通常・ノート・画像リンクの SVG を確認した。文字領域の下端の参照要素との位置差は全組合せで 0px だった。スクリーンショットでサイズ・余白・線端の表示を確認した。これは実エディターでのフォント切替操作の確認とは区別する。
- 一時表示で絵文字指定のマークも確認した。ノート本文や保存済み設定は変更していない。検証用の表示領域は削除済み。
- 短縮切替、ノート切替、カーソル操作、実エディターでのフォント設定の切替は今回の実機確認では未実施。
- 検証後に Inkdrop を通常起動へ戻した。プロセス引数にデバッグ指定がなく、ポート 19222 に接続できないことを確認した。
