# コード記法内のリンクを短縮しない

## 現状と目的

- 現在のリンク検出は文書全体を文字列で走査するため、バッククォートで囲まれた行内コードとコードブロック内の `[label](url)` も短縮する。
- コードとして示したリンク記法は原文のまま表示し、コード領域の外にあるリンクは従来どおり短縮する。

## 修正案

1. `lib/link-compact-extension.js` のリンク検出時に、バッククォートによる行内コードとフェンス付きコードブロックの範囲を判定する。コード領域に重なるリンク候補を短縮対象から除く。
2. 行内コードのバッククォート数、コードフェンスの開始・終了、閉じていないフェンス、コード領域の前後にある通常リンクを回帰テストで確認する。文書編集後の再判定も確認する。
3. `docs/specs/link-detection-and-rendering.md` と `test/README.md` を新しい動作に合わせて更新する。

## 確認

- `npm test` で全テストを実行する。
- 編集した JavaScript ファイルに `node --check` を実行する。
- 必要に応じて Inkdrop v6 のエディター上でも表示を確認する。

## 実施結果

- 行内コードとバッククォートのコードフェンス内のリンクを短縮対象から除外した。
- 回帰テストと仕様書を更新した。`npm test` は 149 件成功し、`node --check` と `npm pack --dry-run` も成功した。
- Inkdrop 6.1.4 を再読み込みし、既存ノートのコードブロック内にあるリンク記法が短縮されず表示されることを画面で確認した。ノート本文は変更していない。
