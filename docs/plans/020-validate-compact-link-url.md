# 短縮対象の URL 条件

## 目的

`[link-compact](a)` のように短縮対象の URL 条件を満たさない記法は、元の表示を維持する。

## 修正案

1. `lib/parser.js` で通常リンクと画像リンクの URL 条件を判定し、対象外の記法を短縮範囲へ追加しない。
2. 通常リンクは `http://` または `https://` の後に 1 文字以上ある場合のみ短縮する。既存のノートリンクの動作は維持する。
3. 画像リンクは `http://`、`https://`、`inkdrop://file:` のいずれかで始まり、その後に 1 文字以上ある場合のみ短縮する。
4. ホスト名の妥当性検証などは追加せず、指定された接頭辞と後続文字の有無で判定する。
5. `test/rendering.test.cjs` に有効・無効な URL と接頭辞だけの場合の回帰テストを追加する。既存テストの入力を新しい仕様に合わせる。
6. `docs/specs/link-detection-and-rendering.md` に短縮対象の条件を反映する。

## 検証

- `npm test` で全テストを実行する。
- 編集した JavaScript の構文チェックを実行する。
- `npm_config_cache=/tmp/link-compact-npm-cache npm pack --dry-run` と `git diff --check` を実行する。
- Inkdrop の実機確認が利用可能か確認し、実施範囲と未実施範囲を記録する。ノート本文や保存済み設定を無断で上書きしない。

## 進捗

- 計画ファイルの作成は承認済み。
- 計画を Shiba で表示し、実装開始は承認済み。
- 既存の操作テストも URL 条件を満たす入力へ変更し、文字列の長さに依存する位置を調整する。
- 実装、回帰テスト、現行仕様とテスト資料の更新済み。
