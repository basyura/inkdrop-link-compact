# Vim の Visual モードで短縮リンクを飛び越える

## 目的

Visual モードで範囲選択を広げたり縮めたりするとき、非表示の URL 内を文字数分移動せず、Normal モードと同様に短縮表示に沿って移動できるようにする。

## 現状

- `lib/interactions.js` の選択補正は空カーソルのみを対象とし、範囲選択を除外している。
- `docs/specs/editing-and-interactions.md` にも範囲選択を補正しないと記載されており、この点は現状の実装と一致する。
- 計画の保存先について、`AGENTS.md` は `.plans/` を指定しているが、既存の計画は `docs/plans/` にある。今回はユーザーが承認した `docs/plans/022-vim-visual-selection.md` を使用する。

## 修正案

1. Vim 側の Visual モードの選択表現とカーソル位置の扱いを確認する。前方選択の終端と実際のカーソル文字の差を考慮する。
2. Visual モードの選択移動にも非表示範囲の補正を適用し、選択の開始位置と向きを維持する。一般の範囲選択、編集中のリンク、文書変更、IME 変換中の処理への影響を避ける。
3. 通常リンク・ノートリンク・画像リンクの左右移動、選択の拡大・縮小、行末・隣接リンクを検証する回帰テストを追加する。Visual 行選択・矩形選択についても影響を確認する。
4. `docs/specs/editing-and-interactions.md` と必要なテスト資料を更新する。

## 追加修正: Visual 選択したリンクの yank

- ユーザー報告: リンクを先頭から末尾まで選択して `y` を実行しても、`p` では `google]` のように隠れた記法が欠ける。
- 修正案: 短縮リンク全体を可視範囲で選択した場合、yank 対象には開始記法と URL 全体を含める。前後方向の選択、通常・ノート・画像リンク、ラベルだけの部分選択を区別し、カーソル移動の補正を維持する。
- Vim の選択とレジスターへの格納処理を確認し、元の Markdown を保持した yank と貼り付けの回帰テストを追加する。仕様と実機確認記録も更新する。
- 実装方針: `y` のキー処理ではなく Visual 選択の実範囲を元の記法まで拡張する。Vim は演算直前にも選択を作り直すため、この時点にも同じ補正を適用する。表示上のカーソル位置はビューごとに別途保持し、URL 末尾まで拡張した選択範囲から移動方向を誤判定しないようにする。
- 実装・仕様更新と回帰テスト追加完了。全 265 テスト成功。ラベルだけの部分選択、短縮記号だけの選択、元記法の選択後の連続移動、演算直前の選択再生成、行単位演算の改行保持も確認した。
- 実機では Inkdrop 内の一時的な実 `EditorView` とインストール済み Vim を使用し、通常・ノート・画像リンク × 前後方向 × 末尾空白あり・なしの 12 ケースで元の記法全体の yank と貼り付けを確認した。システムクリップボードへの影響を避けるため、専用の `a` レジスターで `"ay` と `"ap` を実行した。全ケースでコピー内容と貼り付け後の全文が期待値と一致した。
- 一時ビューは破棄し、検証前のレジスターコントローラーを復元した。保存ノートの本文・設定は変更していない。実ノートでの OS キー入力と他プラグインとの併用は未実施。

## レビュー指摘対応: Visual の変更演算の挿入位置

- 指摘を確認: 選択の開始をラベル先頭から記法先頭まで広げた場合、Vim の `c` は元の記法を削除する一方、挿入位置を拡張前のラベル位置へ戻す。
- 修正案: Vim の文字単位の変更演算による選択全体の削除を、確定したトランザクションで検出する。同じ Vim 操作内で挿入モードへ移行した直後のカーソル設定だけを、実際に削除した範囲の先頭へ補正する。
- 対象は選択の開始が拡張され、実選択全体が削除された場合に限定する。ラベルだけの変更、通常の入力、別の Vim 操作、IME 変換には適用しない。
- 通常・ノート・画像リンク、前置文字、前後方向の選択、空文書・行末を含む回帰テストと、実 Vim の `c` 後に文字を入力する確認を行う。既存の yank とカーソル移動も維持する。
- 対応完了。確定した削除の開始位置と、Vim が復元する拡張前の位置を記録し、同じ操作内の挿入モード移行時だけ補正する。Vim が Visual モードを抜けるために一時的にカーソルを移す場合も、その後の挿入位置復元まで記録を保持する。
- 回帰テスト追加後、全 290 テスト成功。構文チェック、差分チェック、配布内容チェックも成功した。仕様書とテスト資料を更新した。
- 実機では一時的な実 `EditorView` とインストール済み Vim を使用し、通常・ノート・画像リンク × 前後方向 × 前置文字なし・文字列あり・前置行ありの 18 ケースで、`c` の直後の位置と `X` の挿入結果が期待値どおりになることを確認した。専用レジスター `a` を使用し、システムクリップボードへの影響を避けた。
- 既存の yank と貼り付け 12 ケースも実機で再確認し成功した。各一時ビューを破棄し、元のレジスターコントローラーを復元した。保存ノート・設定は変更していない。OS のキーイベント配送と実ノート上での併用操作は未実施。
