# 編集とカーソル操作

## キー操作

- 単一の空カーソルが短縮中の通常リンクまたはノートリンクのラベル内にあるとき、`Enter` はその URL を `inkdrop.appDelegate.openUri` に渡す。リンク先の実際の遷移は Inkdrop に委ねる。
- 単一の空カーソルが短縮中の画像リンク内にあるとき、`Enter` はリンク記法を展開し、カーソルを `!` の直後に移す。改行は挿入しない。
- ラベル先頭またはアイコン直後の `Backspace` と、ラベル末尾の `Delete` は、隠れた記法を削除する前にリンクを展開する。このキー操作自体では文字を削除しない。
- これらのキー操作は、複数選択、範囲選択、IME 変換中、対象リンクが展開中の場合は処理を引き受けない。

## 編集中の展開

- 短縮中のリンク内部を変更し、変更後の選択がそのリンク内にある場合は、対象リンクの記法を展開する。ほかのリンクは短縮したままにする。
- 展開中のリンクを続けて編集する場合は、変更によって文書内の位置がずれても展開を保つ。カーソルまたは選択がリンクから離れると再び短縮する。
- リンクの外側だけを変更した場合は展開しない。記法の完成、URL の変更、記法の破壊には文書の再解析で追従する。
- 短縮解除中は、装飾と専用キー操作を使わず、元の Markdown 記法を直接編集できる。

## 選択と Vim カーソル

- 選択だけが変わるトランザクションで、空カーソルが非表示の `[`、画像の `![`、または `](URL)` の内部へ入った場合、移動方向に応じて可視位置へ補正する。隣接リンクでも補正を繰り返す。
- 範囲選択、文書の変更、エフェクト付き更新、IME 変換中の更新には、この選択補正を行わない。補正時は複数カーソルと主選択を維持する。
- Vim のブロックカーソルが隠れた記法の文字を描画する場合、そのカーソルの文字色だけを透明にする。背景と輪郭は残す。カーソル要素の再生成も監視し、展開・短縮解除・拡張破棄時には専用クラスを外す。
- `h` と `l` は専用キーとして横取りしない。通常の文字入力と Vim 側の移動処理に任せる。
- Vim の通常モードで短縮リンクのラベル先頭に単一の空カーソルがあるとき、`i` の処理前にカーソルをリンク記法の開始位置へ移す。通常・ノートリンクは `[` の前、画像リンクは `!` の前から挿入できる。Vim 側の挿入モードへの切り替えにキー処理を委ねる。範囲選択、複数カーソル、IME 変換中、修飾キー付き操作、挿入・視覚・置換モード、展開中のリンクには適用しない。
- Vim の通常モードで `o` / `O` により行を追加するときは、短縮リンクが行末にあっても Vim の行末への移動を補正しない。ノート切り替え直後の初回操作にも適用する。改行は元のリンク記法の外側に入り、カーソルは新しい行へ移る。通常のカーソル移動時の補正は維持する。
- 初回キー入力時の判定が間に合わず、Vim の改行が行末の短縮リンクの非表示部分へ入ろうとした場合も、同じ編集トランザクション内で改行とカーソルを行末へ移す。挿入モードや通常のリンク編集には適用しない。
