# 起動、切り替え、設定

## 対応環境と起動

- 対応する Inkdrop は v6 以降。編集機能は CodeMirror 6 の `EditorView` を利用する。
- プラグインの有効化時に `link-compact:toggle` コマンドを登録する。アクティブエディターがあれば直ちに短縮を有効にし、なければエディターのロード通知を待つ。
- 有効なエディターだけを処理する。`.editor-layout` が見つからなくても、取得済みエディターへの短縮適用は行う。
- `.editor-layout` の DOM 変化を監視して編集ノートの ID を確認する。別ノートへの切り替えを検知したら短縮状態を有効に戻し、その時点のアクティブエディターに適用する。同じノート、または編集ノートがない場合は状態を変えない。
- `link-compact:toggle` はアクティブエディターの短縮表示を切り替える。無効なエディターでは現在の状態を維持する。同じエディターへの再適用時は既存の CodeMirror 拡張を再設定し、重複登録を避ける。
- プラグインの無効化時はコマンド購読と DOM 監視を解除する。複数エディターの装飾・編集状態は各エディターが保持する。

## 設定

| 設定名 | 対象 | 初期値 |
| --- | --- | --- |
| `link-compact.linkEmoji` | 通常リンク | 空文字列 |
| `link-compact.notelinkEmoji` | `inkdrop://` のノートリンク | 空文字列 |
| `link-compact.imglinkEmoji` | 画像リンク | 空文字列 |

いずれも文字列設定。空文字列なら SVG 矢印、空でなければ設定された文字列を表示する。設定値は装飾を生成するときに読み直す。保存済み設定は初期値より優先されるため、既存の文字設定は自動では空にならない。
