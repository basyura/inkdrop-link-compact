# リンクの検出と表示

## 検出対象

- 文書全体を文字列として走査し、エスケープされていない `[` と `]` を対応付ける。対応する `]` の直後に `(` があり、同じ行に閉じ `)` があるリンクを対象にする。
- `(` と `)` の入れ子を数えて URL の終端を決める。URL が空の場合と、閉じ `)` より前に改行がある場合は短縮しない。
- ラベルは空でもよい。ラベル内の角括弧は表示したままにする。対応する `[` の直前に `!` があれば画像リンクと判定する。
- URL が `inkdrop://` で始まる通常リンクはノートリンクとして扱う。画像判定が優先されるため、画像の URL が `inkdrop://` で始まっても画像リンクの設定を使う。
- Markdown の構文木は使わない。コード領域内の記法も対象となり、タイトル付きリンクの丸括弧内全体を URL として扱う。CommonMark 全体への準拠は保証しない。

## 短縮表示

- 元の Markdown 本文は変更しない。通常・ノートリンクでは先頭の `[`、画像リンクでは `![` を非表示にする。
- ラベルの文字は残し、続く `](URL)` を 1 個の `span.link-compact-mark` に置き換える。外側の `span` の `data-url` には、丸括弧内の元の文字列を保存する。
- 短縮中のリンク全体には `link-compact-enabled` クラスを付ける。短縮を解除するか、そのリンクを編集中に展開すると、元の記法を表示する。
- 非表示部分は CodeMirror 6 の置換装飾と `atomicRanges` に登録し、カーソル移動で 1 単位として扱う。ラベル内の文字は編集できる。
- 設定値が空の場合は右上向きの SVG 矢印を表示する。矢印は `currentColor` の線で描き、装飾用の SVG には `aria-hidden="true"` と `focusable="false"` を設定する。
- 設定値が空でなければ、その文字列をテキストとして表示する。空白だけの設定も明示された文字列として扱い、HTML として解釈しない。

## スタイル

- `styles/link-compact.css` は置換要素を `font-size: 90%` にする。SVG の幅と高さは `1em`、左余白は `0.15em`、縦位置は `-0.125em`、不透明度は `0.65`。
- `link-compact-enabled` は短縮中のリンクにだけ付くため、ユーザーの CSS から表示を調整できる。
- `link-compact-label-bracket` と `link-compact-url-bracket` のクラスは出力しない。
