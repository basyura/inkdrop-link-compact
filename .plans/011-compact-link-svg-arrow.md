# 短縮リンクを右上向きの SVG アイコンで表示する

## 状態

- 実装とローカル検証を完了。Inkdrop 実機で未設定時の SVG 表示を確認済み。
- このセッションでは本ファイルを使用する。

## 目的

URL の代わりに表示する絵文字の設定は維持し、デフォルトを未設定（空文字）にする。未設定の場合は Inkdrop のバックリンクと同じ線の細い SVG 矢印を表示し、絵文字が指定されている場合はその文字を表示する。矢印は右上向きにし、ユーザーの stylesheet で `[ ] ( )` が非表示でも、表示名の直後になじむ見た目にする。

1. `lib/link-compact-extension.js`
   - `LinkCompactWidget` は絵文字が指定されていれば従来どおり文字を描画し、未設定（空文字、`null`、`undefined`）の場合にインライン SVG を生成する。
   - ユーザーが提示した `viewBox="0 0 24 24"`、`stroke-width="1.5"`、丸い線端・角の形状を使用する。
   - 元のパスを `(x, y) → (24 - x, 24 - y)` で変換した右上向きの座標を直接使用し、回転指定を不要にする。
   - `document.createElementNS` で SVG 要素を生成し、線の色は `currentColor` とする。
   - 外側の `span.link-compact-mark` と、元の URL を保持する `data-url` 属性を維持する。
   - アイコンは装飾として `aria-hidden="true"` を指定する。
   - 通常リンク・ノートリンク・画像リンクそれぞれの設定を参照し、未設定の種類だけ同じ右上向き矢印を表示する。
   - ウィジェットの比較では、既存どおり絵文字設定と URL の両方を比較する。
2. `styles/link-compact.css`
   - アイコンの幅・高さを `1em` とし、既存の文字サイズ 90% を基準に調整する。
   - 控えめな不透明度、表示名との小さな余白、縦位置を指定する。
   - SVG の範囲に限定してスタイルを適用し、表示名や行高への影響を確認する。
3. `lib/link-compact.js`
   - `linkEmoji`、`notelinkEmoji`、`imglinkEmoji` の 3 項目を残し、デフォルト値をすべて空文字に変更する。
   - 各設定の説明に、空欄なら右上向きの SVG、文字を指定すればその文字を表示することを記載する。
   - 既に明示的に保存されている絵文字は引き続き使用し、空欄にすると SVG 表示へ切り替わる。
   - ユーザーの保存済み設定ファイル自体は書き換えない。
4. `README.md`
   - 表示仕様、設定説明、生成 HTML の例に、未設定時の SVG と指定時の絵文字の両方を記載する。
   - 提示された SVG の出典情報を保持する。
