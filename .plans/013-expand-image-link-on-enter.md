# 画像リンク上の Enter で一時的に短縮を解除する

## 目的

短縮表示中の画像リンク上で Enter を押すと、改行せずにその画像リンクの URL を表示して編集できるようにする。カーソルがリンク外へ移動したら再短縮する。

## 修正案

- `lib/link-compact-extension.js` の既存の Enter 処理に画像リンクの分岐を追加する。
- 画像リンクの構文内を対象とし、短縮された URL の前後も含める。構文全体の外側のカーソル位置は対象外とする。
- 単一カーソルで選択範囲がなく、変換中でなく、対象画像リンクが短縮表示中の場合にだけ処理する。
- 専用の StateEffect を dispatch し、ViewPlugin の更新処理で対象リンクを既存の編集状態に追加して短縮表示とカーソル移動の制限を解除する。本文とカーソル位置は維持する。
- リンク内のカーソル移動や編集では展開を維持し、リンク外への移動では既存の編集終了処理を使って再短縮する。
- Enter を処理済みとして本体へのイベント伝播を止め、改行や画像の起動を発生させない。
- 展開済み画像リンク、範囲選択、複数カーソル、変換中では通常のキー操作に委ねる。通常リンクとノートリンクのタイトル上でリンク先を開く既存動作を維持する。
- 必要に応じて README.md に操作方法を追記する。
